## Default Permission

Every command of the assistant and its privacy settings.

#### This default permission set includes the following:

- `allow-agent-status`
- `allow-agent-install`
- `allow-agent-connect`
- `allow-agent-code`
- `allow-agent-disconnect`
- `allow-agent-cancel`
- `allow-agent-run`
- `allow-agent-attach`
- `allow-agent-files`
- `allow-agent-seen`
- `allow-agent-level`
- `allow-agent-detach`
- `allow-agent-in-scope`
- `allow-agent-forget`
- `allow-provider-connect`
- `allow-provider-models`
- `allow-chats-list`
- `allow-chat-save`
- `allow-privacy-policy`
- `allow-privacy-options`
- `allow-privacy-pages`
- `allow-privacy-view`
- `allow-privacy-override`
- `allow-privacy-overrides`
- `allow-privacy-forget`
